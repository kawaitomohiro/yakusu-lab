FOR TEACHERS先生の方へ

ねらい
「約数＝わり切れる数」を、マス目から選ぶ操作で体にしみこませます。 選ぶ → 重なりを見る → いちばん大きいものを選ぶ、という同じ流れの続きとして 約数・公約数・最大公約数をつなげています。

使い方
URLを開くだけで始まります。ログインも名前の入力もありません。 記録はその端末の中だけに保存され、スプレッドシートには何も残りません （共用端末では前の子の記録が残ります。気になるときは「記録」→「記録をすべて消去」）。

時間の目安
1セット5問でおよそ3分、タイムアタックは60秒。朝学習・すき間時間・自由進度のどこにでも差し込めます。

くり返させる仕掛け
ミッションごとにB→A→Sのランクがあります。Bはクリア、Aはタイムアタック6問、Sは10問。 一度クリアした後も、ランクを上げるために戻ってきます。

つまずいたとき
まちがえた問題では、足りない数を「◯×◯＝◯」の形で、よけいな数を「あまり」つきの式で示します。 ミッション01・02をくり返すだけでも、拾い落としは目に見えて減ります。
